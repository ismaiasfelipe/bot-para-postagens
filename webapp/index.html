Esse app controla o bot de postagens direto pelo GitHub Actions — sem servidor próprio. Precisa de um token de acesso pessoal do GitHub, restrito a este repositório.

Como criar o token?
  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: "Only select repositories" → escolha este repositório.
  3. Permissions → Repository permissions: "Actions" = Read and write, "Contents" = Read-only.
  4. Gere e cole o token acima. Ele fica salvo só neste navegador.
